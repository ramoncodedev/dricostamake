# Dri Costa · Link bio

Link bio de **Dri Costa — Maquiagem e Penteado** ([@dricostamakeup](https://www.instagram.com/dricostamakeup/)).
Atendimento em Eunápolis, Arraial d'Ajuda, Trancoso, Porto Seguro e região (BA).

## Estrutura

```
index.html      estrutura da página
css/style.css   estilos (paleta rosa, Fraunces + Plus Jakarta Sans, responsivo)
js/main.js      links do WhatsApp, carrossel, animações e fallback de fotos
img/            fotos do portfólio
```

## Fotos

As fotos ficam em `img/`. Os espaços do layout usam `foto-6.jpg` a `foto-15.jpg` e `port-*.jpg`.
Se uma foto não existir, o card mostra um fundo rosa com "Dri" e, no portfólio, o quadro é escondido.

## Rodar localmente

Abra o `index.html` no navegador — não precisa de build.
